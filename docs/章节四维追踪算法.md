# 章节四维追踪算法

> 引擎：`src/novel_writer/core/chapter_tracker.py` → `track_all(mem, chapter, content)`
> 写入目标：[长期记忆](长期记忆算法.md) 的 4 个桶
> 调用点：[写后沉淀算法](写后沉淀算法.md)（每章正文写完后）
> 测试：暂无专属测试

## 一句话总结

从章节正文用**正则 + 关键词**自动提取四维数据写入记忆：资源账本（得失物品）、情感弧线（角色情绪）、信息边界（谁知道什么）、支线进度（推进/停滞/完结）。纯规则，不调 LLM。

## 四维口径

### 1. 资源账本（`resources`）

| 动作 | 正则模式 | 示例 |
|------|----------|------|
| 获得 | `X(获得\|得到\|拿到\|捡到\|收到\|夺取\|抢到)了?Y` | 凌尘获得了一枚灵石 |
| 赠予 | `X（给了\|递给\|送给\|赠予\|交给）了?Z Y` | 老者递给凌尘一把剑 |
| 失去 | `X(失去\|丢失\|丢掉\|损坏\|破碎\|用尽\|消耗)了?Y` | 凌尘丢失了玉佩 |
| 被夺 | `X被W(抢走\|夺走\|偷走\|毁坏)了?Y` | 剑被敌人抢走了 |

- 主体 `X`：`\w{2,6}`（2–6 字）
- 物品 `Y`：去掉首尾 `了/的` 后长度 2–20
- 写入：`aspect="持有:Y"` 或 `"失去:Y"`，`payload={"action", "item"}`

### 2. 情感弧线（`emotional_arcs`）

10 种情绪 × 关键词族：

| 情绪 | 关键词 |
|------|--------|
| 愤怒 | 怒/愤怒/暴怒/恼火/气得/咬牙/握拳 |
| 悲伤 | 悲伤/难过/伤心/泪/哭泣/哽咽/心碎 |
| 恐惧 | 恐惧/害怕/畏惧/颤抖/惊恐/毛骨悚然 |
| 喜悦 | 高兴/开心/喜悦/笑了/兴奋/激动/欢呼 |
| 惊讶 | 惊讶/震惊/目瞪口呆/不敢相信/惊愕/没想到 |
| 平静 | 平静/淡定/冷静/从容/不动声色 |
| 坚定 | 坚定/决心/毅然/毫不犹豫/义无反顾 |
| 迷茫 | 迷茫/困惑/不解/疑惑/茫然 |
| 绝望 | 绝望/崩溃/万念俱灰/心如死灰/放弃 |
| 愧疚 | 愧疚/自责/内疚/后悔/懊悔 |

**角色归属**：在情绪词前 0–10 字内找 `\w{2,6}` 人名（过滤 `这个/那个/什么/怎么/为什么`）。每角色每情绪每章只记一次（命中即 break）。

写入：`aspect="第{ch}章情绪"`，`value=情绪词`。

### 3. 信息边界（`info_boundary`）

| 方向 | 正则 | aspect |
|------|------|--------|
| 已知 | `X(得知\|知道\|了解\|发现\|明白\|意识到\|领悟到)了?INFO` | `已知信息` |
| 传播 | `X(告诉\|告知\|透露\|坦白\|解释)了?Z INFO` | `已知信息`（记在 X 名下） |
| 未知/隐瞒 | `X(不知道\|不清楚\|隐瞒\|瞒着\|没告诉\|没说\|欺骗)W INFO` | `未知信息`，`payload.hidden=True` |

- INFO 长度限制：已知 5–60 字，未知 3–40 字（写入时再截断）

### 4. 支线进度（`subplots`）

6 类支线信号：

| 支线 | 关键词 |
|------|--------|
| 感情线 | 喜欢/爱/心动/表白/在一起/分手/告白/约会 |
| 复仇线 | 仇/报复/报仇/清算/偿还/代价 |
| 成长线 | 突破/修炼/领悟/变强/晋升/觉醒 |
| 探索线 | 探索/发现/秘密/真相/调查/线索 |
| 权谋线 | 势力/权力/阴谋/背叛/联盟/政变 |
| 冒险线 | 冒险/任务/挑战/战斗/对决/试炼 |

**触发**：同支线关键词命中 ≥2 个。进度判定：

| 信号 | 进度 |
|------|------|
| 含 完成/结束/解决/告一段落 | `完结` |
| 含 停滞/搁置/暂时 | `停滞` |
| 其余 | `推进中` |

写入：`value="{进度}: {关键词前后±10/30字片段}"`。

## 与写后沉淀的分工

| 步骤 | 负责模块 | 提取内容 |
|------|----------|----------|
| 状态变化（突破/受伤/位置） | [写后沉淀](写后沉淀算法.md) `sediment_chapter` | `character_state` 桶 |
| 伏笔线索 | 写后沉淀 | `open_loops` 桶 |
| 章节事件 | 写后沉淀 | `story_facts` 桶 |
| 资源/情感/信息/支线 | **本文档** `track_all` | 对应 4 桶 |

## 边界与已知限制

- 纯正则，误报/漏报常态。人名 `\w{2,6}` 会把非人名（「这个」「一阵」）当主体——情绪追踪有停用词过滤，资源/信息边界**无**。
- 赠予模式第二个正则的分组与取物品逻辑依赖 `groups[3]/groups[-1]`，对变长匹配较脆弱。
- 支线进度每章每支线只写一条（`break` 在第一个命中关键词），同章多次推进不累加。
- `track_all` 的异常被写后沉淀 `try/except` 吞掉（debug 级），四维失败不影响记忆主流程。
