# 叙述语言与大白话约束

> 引擎：`src/novel_writer/core/narrative_voice.py`
> 注入：`workflow/context.py`（`chapter` / `polish` 头部）+ `workflow/definition.py` 步骤提示词
> 落盘：`meta.json` 的 `narrative_voice` 字段（默认「大白话」）
> 测试：`tests/test_narrative_voice.py`

## 一句话总结

长篇正文的第一要求是「读得下去」，不是「单句漂亮」。项目可选三档叙述语言（`大白话` / `平实` / `文学`），默认大白话；写作与润色时注入**带阈值的硬约束**，质量检查按同一套阈值做**不计分的文绉绉体检**。

## 为什么需要它

模型写长篇的默认倾向是「每一句都想写好」：成语、比喻、四字词、书面腔、凑字副词层层叠加。单章看很漂亮，几百章连读会累，而且文风会随润色轮次越来越飘。这个模块把「平一点」写成可执行的规则，而不是一句「文笔自然」。

## 三档预设

| 档位 | 定位 | 成语/千字 | 书面腔/千字 | 比喻/千字 | 凑字副词/千字 | 平均句长 |
|------|------|-----------|-------------|-----------|----------------|----------|
| `大白话`（默认） | 短句、口语、少修辞 | ≤3 | ≤2 | ≤1 | ≤2 | ≤18 字 |
| `平实` | 正常书面语、克制 | ≤8 | ≤5 | ≤3 | ≤5 | ≤22 字 |
| `文学` | 允许修辞与节奏经营 | ≤15 | ≤10 | ≤6 | ≤8 | ≤28 字 |

阈值定义在 `_PROFILES`；`normalize_voice()` 负责把旧值/别名（口语、朴素、文艺…）归一到三档，未知值按大白话。

## 注入链路

```
项目 meta.narrative_voice
  → workflow_mixin 组 project_info
  → build_workflow 写入 workflow.project（顺带归一）
  → ContextBuilder.build(step_id)
      ├─ chapter：头部注入 `=== 【语言质感 · 档位（硬约束）】 ===`
      └─ polish ：同样注入；提示词改为「减法润色」
  → Agent system_prompt + chapter-craft 技能也写死语言底线
```

- 约束块只在 `_VOICE_STEP_IDS = {chapter, polish}` 注入，规划和审稿不背这套规矩。
- 旧项目的 `workflow.json` 没有该字段时，`_build_voice_block()` 回退读 `meta.json`，再缺省按大白话。
- 约束块含 10 条可执行规则 + 一条「风格提醒」：标称「史诗宏大」不等于句子要文绉绉，宏大靠事件规模和代价，不靠形容词。
- 润色步骤的提示词从「提升文笔」改为「减法润色」：大白话/平实档删形容词/成语/比喻/凑字副词、把书面腔改土、拆长句；文学档只删冗余，保留有信息量的修辞。两档都禁止新增修辞。
- 断点续跑时 `refresh_builtin_workflow` 会核对步骤结构，用当前模板替换旧 `workflow.json` 里的老提示词（结构被改过则保留原样）。

## 体检口径（`measure_voice`）

统计每千字密度：高频成语词表、书面词表（然而/旋即/须臾/与此同时…）、比喻正则（仿佛/宛如/像…一样）、凑字副词（淡淡的/微微/缓缓/一丝/一抹…）、平均句长（按 `。！？!?…` 切句）。正文不足 300 字只算指标不判超标。

结果写入 `QualityReport.voice_metrics` / `voice_issues`，在质量报告里单列「语言质感」小节；**不参与总分，也不进 `issues`/`suggestions`**。定位是提示「可能文绉绉」，不是判定好坏。

## 与梗密度的关系

「口语化不等于网络梗」是默认口径，但项目可以显式开梗：

- `meme_level=无`：语言约束写「仙侠/历史题材不用现代流行语」；
- `meme_level=少/中/高`：改成「现代梗按【梗密度】控制，不要超量」，用量、场合、选梗交给 [梗密度与现代梗](梗密度与现代梗.md)。

两条规则不会同时要求「不用」和「多用」；写作 Agent 的系统提示词也按同一口径改为「没开就不玩，开了也不超量」。

## 边界

- 词表只覆盖高频项：漏检不代表不文绉绉，命中也不代表一定差。
- 约束是提示词，模型可能不遵守；质量检查的提示只写报告，不会自动回炉重写。
- 修改默认档位只需改 `DEFAULT_VOICE`；修改阈值只需改 `_PROFILES`，上下文约束与体检会同步生效。
- 已写章节不会自动重写：新设置只影响之后生成的章节。
