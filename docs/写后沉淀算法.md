# 写后沉淀算法

> 引擎：`src/novel_writer/core/workflow/sediment.py` → `sediment_chapter(project_dir, chapter, content)`
> 调用点：工作流 runner 在章节正文步骤完成后自动调用
> 落盘：`memory.json` + `reading_power.json`

## 一句话总结

每章正文写完后自动做两件事：**(1) 从正文抽取记忆项**（状态变化/伏笔/章节事件 + 四维追踪）写入长期记忆；**(2) 追读力分析**落盘。全链路纯规则，不调 LLM。

## 沉淀管线

```
章节正文
  │
  ├─► ① 状态变化抽取 ──► memory.character_state
  ├─► ② 伏笔线索抽取 ──► memory.open_loops
  ├─► ③ 章节事件记录 ──► memory.story_facts
  ├─► ④ 四维追踪 ─────► memory.{resources,emotional_arcs,info_boundary,subplots}
  │         (chapter_tracker.track_all)
  ├─► ⑤ 伏笔自动回收 ──► close_loop（回收信号词检测）
  ├─► memory.compact() + save()
  │
  ├─► ⑥ 反模式过期清理 ─► anti_patterns.json（clear_resolved）
  │
  └─► ⑦ 追读力分析 ────► reading_power.json
            (ReadingPowerTracker.analyze+record)
```

## 各步口径

### ① 状态变化 → `character_state`

| 方面 | 正则 | 示例 |
|------|------|------|
| 实力变化 | `X(突破\|晋升\|升级\|进阶)` | 凌尘突破 |
| 身体状态 | `X(受伤\|重伤\|濒死\|死亡\|陨落)` | 凌尘受伤 |
| 位置变化 | `X(到达\|来到\|离开\|前往\|回到)` | 凌尘来到 |

主体长度限制 2–6 字。`value` 为整个匹配串。

### ② 伏笔线索 → `open_loops`

| 模式 | 示例 |
|------|------|
| `竟然\|居然\|原来\|没想到\|殊不知` + 5–40 字 | 竟然发现灵脉异常 |
| `如果\|倘若\|万一` + 5–40 字 | 如果那枚玉佩是真的… |

- `subject` = `第{ch}章伏笔{序号}·{摘要24字}`（含序号+片段，**同章多伏笔互不覆盖**）
- `aspect` = `悬念`
- `value` 截断 60 字
- `payload.urgency = 0.6`（固定中等紧急度）

### ③ 章节事件 → `story_facts`

- `subject` = `第{ch}章 {标题}`（标题取正文第一个 Markdown 标题，无则 `第{n}章`）
- `value` = 首段前 100 字

### ④ 四维追踪

委托 [章节四维追踪算法](章节四维追踪算法.md) 的 `track_all`。失败仅 debug 日志，不中断。

### ⑤ 伏笔自动回收（`_auto_close_loops`）

正则匹配回收信号词（「原来如此」「真相大白」「谜底揭开」「终于明白」等）→ 提取信号上下文 → 与 `open_loops` 的关键词（2-4 字中文片段）子串匹配 → 命中自动 `close_loop`。漏报可接受（注意力尾部持续提醒），误报有审计链可追溯。

### ⑥ 追读力

委托 [追读力算法](追读力算法.md)。失败仅 debug 日志。

## 标题提取（`extract_chapter_title`）

扫描正文行，匹配 `^#{1,3}\s+(.+)$`，清理 `*_`#\[]()` 等符号，截断 50 字。找不到返回 `第{n}章`。

## 压缩时机

`mem.compact()` 在 `save()` 前调用——见[长期记忆算法](长期记忆算法.md)。保证每次沉淀后 outdated 链不会无限膨胀。

## 边界与已知限制

- 状态变化正则的主体 `\w+` 会漏过常见词（有 2–6 字限制但仍不完美）。
- 追读力/四维追踪的失败被吞（debug），生产排障需开 debug 日志。
- 沉淀是**幂等的同章覆盖**（memory 同键覆盖、reading_power 同章覆盖），重跑安全但会丢失上一次的 outdated 审计细节（被 compact 清掉）。
- 反模式清理阈值固定 10 章（见[反模式追踪算法](反模式追踪算法.md)）。
