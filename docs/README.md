# docs 总索引

> **一句话总结**：本目录**唯一**的文档总目录。新增文档必须在此登记一行，否则等于没有存在过——
> 根目录 `README.md` 与 `DEV_GUIDE.md` 里各有一份**硬编码**的文档清单会逐渐漂移，
> **以本文件为准**。维护约定见文末。

**性质标签**：`算法`=原理说明，长期有效 ｜ `规范`=约定/标准，改动需同步代码 ｜ `参考`=人读手册
｜ `计划`=做完即过期 ｜ `记录`=一次性留档 ｜ `墓碑`=已废弃，只留重定向

## 与枢纽清单的关系

| 位置 | 现状 | 处理 |
|---|---|---|
| 根 `README.md` | 特性/快速开始/结构简介 | 保持面向用户的入口；算法细节**不在此展开**，需要时链到本文件 |

**维护约定**：以后新增文档，**只在本文件登记**，不要再往 `README.md` / `DEV_GUIDE.md` 里加清单
（多处维护同一份列表必然漂移）。算法口径改动：先改代码 → 反哺对应 `算法` 文档 → 检查「权威归属」表是否需调整。
