# 质量检查算法

> 引擎：`src/novel_writer/core/quality_checker.py` → `QualityChecker.check_chapter(content, chapter) -> QualityReport`
> 界面：工作流内置步骤 `quality_check`（每章触发）→ 写入 `review/质量检查报告.md`
> 测试：`tests/test_quality_checker.py`

## 一句话总结

对单章正文做 **10 维规则打分**（篇幅/结构/对话/场景/节奏/钩子/爽点/微兑现/一致性/句式），加权合成 0–100 总分，同时产出问题列表与建议列表。纯规则引擎，不调 LLM。

## 十维口径

| 维度 | 字段 | 权重 | 判据摘要 |
|------|------|------|----------|
| 篇幅 | `word_count_score` | 0.10 | 中文字数+英文单词数，3000–4000 最佳 |
| 结构 | `structure_score` | 0.10 | 标题存在、段落数、首尾钩子词 |
| 对话 | `dialogue_score` | 0.15 | 对话数量、标签多样性、动作描写 |
| 场景 | `scene_score` | 0.10 | 五感关键词覆盖种类与密度 |
| 节奏 | `rhythm_score` | 0.15 | 转折词、紧张词出现次数 |
| 钩子 | `hook_score` | 0.10 | 5 类钩子关键词的多样性与强度 |
| 爽点 | `cool_point_score` | 0.10 | 4 类爽点模式命中数 |
| 微兑现 | `micro_payoff_score` | 0.05 | 4 类微兑现模式命中数 |
| 一致性 | `consistency_score` | 0.10 | 人称混用比例 |
| 句式多样性 | `sentence_variety_score` | 0.05 | 句首 2 字重复率 + 高频词惩罚 |

**总分** = Σ(维度分 × 权重)，截断到 `[0, 100]`。

## 各维细则

### 篇幅

字数统计：`cn_chars`（U+4E00–U+9FFF）+ `en_words`（`[a-zA-Z]+` 正则）。

| 字数区间 | 得分 |
|----------|------|
| 3000–4000 | 100 |
| 2500–3000 / 4000–4500 | 80 |
| 2000–2500 / 4500–5000 | 60 |
| 其余 | 40 + issue |

### 结构

基准 60 分。加分项：前 5 行有 `#` 标题 +10；段落数 ≥10 +15 / ≥5 +10（否则 issue）；正文 >1000 字时，首 1/3 含 `？！突然忽然` +10，末 1/3 含 `？！然而但是却` +10。

### 对话

- 对话引号正则：`["「"](.*?)["」"]`
- 标签词：`说|道|问|答|喊|叫|笑|哭|怒|惊|叹`
- 动作描写：人称代词 + 2–10 字 + 时态助词（`着|了|过|起来|…`）

数量 ≥10 +15 / ≥5 +10 / <3 issue；标签去重 ≥5 +15 / ≥3 +10；动作描写 ≥5 +10。

### 场景（五感）

| 感官 | 关键词族 |
|------|----------|
| 视觉 | 看/见/望/视/瞧/盯/瞪/瞅 |
| 听觉 | 听/闻/声/音/响/鸣/叫 |
| 触觉 | 触/摸/感/觉/冷/热/软/硬 |
| 嗅觉 | 香/臭/味/气/息 |
| 味觉 | 甜/苦/酸/辣/咸 |

覆盖种类 ≥4 +20 / ≥3 +15 / ≥2 +10；总出现次数 ≥20 +20 / ≥10 +15 / ≥5 +10。

### 节奏

- 转折词：`突然|忽然|然而|但是|却|竟然|居然|没想到|殊不知`
- 紧张词：`危险|死|杀|逃|追|攻击|战斗|冲突`

转折 ≥3 +20 / ≥2 +15 / ≥1 +10；紧张 ≥5 +20 / ≥3 +15 / ≥1 +10。

### 钩子 / 爽点 / 微兑现

与 [追读力算法](追读力算法.md) **共用同一套关键词表**（`hook_keywords` / `cool_keywords` / `micro_keywords`），但评分口径不同：质量检查看多样性+强度，追读力看主类型+强度分档。**关键词表改动必须两处同步**。

### 一致性

统计 `我` 与 `他/她` 出现次数，若双方均 >0 且 `min/max > 0.3`，判为混用人称，issue + 扣 10 分。

### 句式多样性

按 `。！？` 切句，取前 20 句的句首 2 字，计算去重率：

| 去重率 | 得分 |
|--------|------|
| ≥0.8 | +25 |
| ≥0.6 | +15 |
| ≥0.4 | +10 |
| <0.4 | issue |

高频词惩罚：`突然/不禁/竟然/居然/忽然` 每个出现 >3 次，suggestion + 扣 5 分。

## 数据结构

```python
@dataclass
class QualityReport:
    chapter: int
    total_score: float          # 0-100
    word_count: int
    word_count_score: float     # 以下 10 个维度分
    structure_score: float
    dialogue_score: float
    scene_score: float
    rhythm_score: float
    hook_score: float
    cool_point_score: float
    micro_payoff_score: float
    consistency_score: float
    sentence_variety_score: float
    issues: list[str]           # 问题
    suggestions: list[str]      # 建议
```

`generate_report_text(report)` 输出 Markdown 报告（各维得分 + 问题 + 建议）。

## 边界与已知限制

- 纯关键词/正则，**不理解语义**——关键词命中≠好文，缺命中≠差文。定位是**快速筛**，不是终审。
- 对话正则只认 `"…"` `「…」` `『…』`，不认中文弯引号 `“…”`。
- 一致性检查目前只做人称比对，角色名一致性（代码注释已标明「简化处理」）**未实现**。
- 角色名提取逻辑残留（从对话中提取 `我/你`）实际未参与评分，仅为占位。
