# 战斗场景写法

## 1. 先定「空间」
开打前用 1–2 句锁定：谁在哪、距离多远、有什么障碍/高低差/可借用的物件。
战斗中每换一次位置，都要让读者知道相对关系。

## 2. 回合结构（3–5 拍）
1. **试探**：双方亮出第一手，读者建立实力预期。
2. **压制**：一方占优，另一方暴露弱点或底牌。
3. **反转**：弱势方用信息差/环境/代价翻盘。
4. **结算**：胜负落定，但留下后果（伤、暴露、结仇、消耗）。

不要写成「你一拳我一脚」的流水账；每一拍都要改变局面。

## 3. 代价
- 赢要付代价：受伤、暴露身份、耗掉底牌、波及无辜。
- 输要有收获：逼出情报、拖住时间、让对手付出代价。
- 避免「毫发无伤碾压」连续出现；爽点需要稀缺。

## 4. 节奏
- 短句、动词优先；危险瞬间用断句。
- 不用连续三段解释招式原理；设定拆碎，边打边给。
- 旁观者反应只写一句，用来放大结果，不要抢戏。

## 5. 收尾
- 最后一句落在**后果**或**新威胁**上，不要落在「众人震惊」。
- 检查：伤势、消耗、损坏的物品、目击者、时间，下一章要能接上。
