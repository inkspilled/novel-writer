# 连续性自检清单

逐项对照前文与设定，发现冲突时以「已落盘正文 + 记忆/世界状态」为准，不要凭印象改。

## 1. 人物
- 姓名、称呼、称号是否前后一致？有没有同人异名/异人同名？
- 境界/等级/能力有没有跳变？突破是否有过程与代价？
- 伤势、中毒、残疾、寿命等状态是否延续？
- 性格与说话方式有没有突然漂移？

## 2. 物品
- 获得的物品是否登记？失去/消耗/损毁是否交代？
- 一次性道具是否被重复使用？
- 物品的能力边界是否被随意扩大？

## 3. 时空
- 当前时间、地点、天气是否与前章衔接？
- 移动耗时是否合理？有没有「瞬间到达」？
- 多线并进时，各线时间是否对齐？

## 4. 关系与信息
- 谁知道什么？谁不该知道？有没有角色凭空知道秘密？
- 关系变化有没有事件支撑？
- 承诺/威胁/交易是否被遗忘？

## 5. 世界规则
- 力量体系、禁忌、代价是否被遵守？
- 新设定是否与旧设定冲突？冲突时优先保旧设定。

## 6. 输出
发现冲突时，优先用**最小改动**修（改一句动作/一句台词），不要重写整章。
无法判断时，标注「待确认」，不要编造新设定。
