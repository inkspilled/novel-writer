# 情感戏写法

## 1. 先定「情绪转折」
一场情感戏只承担一个转折：
- 信任 → 怀疑
- 依靠 → 失去
- 恨 → 理解（但不一定和解）
- 期待 → 落空

写之前用一句话写清「进场时是什么关系，出场时变成什么」。

## 2. 克制
- 越重的情绪，越不要直接命名。不写「他悲痛欲绝」，写他做了什么、没做成什么。
- 让人物在情绪最高点做一件**日常小事**（收拾碗筷、系鞋带、关窗），比嚎啕更疼。
- 允许人物说错话、迁怒、沉默；完美受害者没有真实感。

## 3. 身体细节
选 1–2 个生理反应：喉咙发紧、手指发麻、耳鸣、闻不到味道、时间变慢。
不要每个情绪都写「眼眶一热」「心如刀绞」。

## 4. 关系变化要「落地」
情绪过后，必须留下一个可追踪的变化：
- 称呼变了
- 站位/距离变了
- 一件信物给出或收回
- 一个秘密说出或咽回
下一章要能通过这个变化看出关系不同了。

## 5. 节奏
- 情绪爆发前放慢，爆发时用短句，爆发后留白。
- 不要用大段回忆解释「为什么这么痛」；把原因拆进动作和对话。
- 旁观者只做镜子，不替读者感动。
