# 对话戏写法

## 1. 每场对话都要有「议题」和「暗线」
- 明面议题：他们在谈什么（资源、去向、条件）。
- 暗线：各自真正想要什么（拖延、套话、保命、试探立场）。
- 好的对话结束时，明面议题可能没解决，但暗线已经变化。

## 2. 意图 > 台词
写每句台词前标注它的功能：施压 / 回避 / 试探 / 让步 / 激怒 / 示弱。
没有功能的台词删掉。

## 3. 潜台词
- 人物不直说自己的真实目的；用条件、反问、类比、旧事来暗示。
- 读者能听懂，但对话中的另一方不一定听懂——这个落差就是戏。

## 4. 人物声线
- 用词、句长、称呼、口头禅区分人物；不要让所有人都说完整、礼貌、逻辑严密的话。
- 上位者多用短句和反问；心虚者多解释；愤怒者会重复和打断。

## 5. 动作替代标签
- 用「他把杯子推回去半寸」代替「他拒绝地说」。
- 关键停顿用动作/环境补，不要写「空气安静了几秒」这种套话。
- 三人以上对话，用视线和站位提示谁在听。

## 6. 自检
- 遮住人名，能否分辨谁在说话？不能就改声线。
- 有没有一段话是在向读者解释设定？有就改成冲突中的信息。
- 对话后局面变了吗？没变就压缩。
